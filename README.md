# Flashito para Windows

Aplicación de bandeja para Windows 10/11 que responde preguntas seleccionadas mediante una API compatible con OpenAI.

## Uso

1. Compila con `build.bat` o utiliza el ejecutable publicado en Releases.
2. Ejecuta `Instalar.bat`.
3. Configura tu endpoint, API key y modelo.
4. Selecciona una pregunta y presiona `Ctrl+Alt+F`.

La API key se guarda únicamente en el equipo del usuario. No incluyas claves personales en el repositorio.

## Compilación

`build.bat` utiliza el compilador de C# incluido con .NET Framework en Windows.
